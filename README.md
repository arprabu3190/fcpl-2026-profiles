# FCPL 2026 Player Profile Showcase

## Files to publish
Upload `index.html`, `styles.css`, `data.js`, and `app.js` to a public GitHub repository.

## Edit team names
Open `data.js` and edit only the values in `window.FCPL_TEAMS`. Keep quotation marks and commas.

## Publish using GitHub Pages
1. Create a public GitHub repository named `fcpl-2026-profiles`.
2. Upload the four website files to the repository root.
3. Open Settings > Pages.
4. Choose Deploy from a branch, then `main` and `/(root)`.
5. Save and wait a few minutes for the public link.

## Age privacy
The player age is not displayed. Categories are: Young Talent up to 25, Prime 26-30, Experienced 31-39, Seasoned 40-44, Veteran 45+.

## Auction allocation
Use Admin to choose Available, Sold, Unsold, or Withdrawn. Team and sold price appear only when Sold is chosen.

## Free-version limitation
Changes are stored in the current browser only. Use Export results frequently. Use Import results to restore a backup on another browser or laptop. Public viewers do not receive live changes automatically.

## Photo permissions
Google Drive photos must be shared as Anyone with the link - Viewer. If a photo cannot load, the website shows player initials.
