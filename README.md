# FCPL 2026 fixed one-screen showcase

This is a full replacement package. Do not append old CSS. Replace all existing website files with these files:
- index.html
- styles.css
- app.js
- data.js
- fcpl-logo.png

The desktop showcase is locked to the browser height and all photos use the same fixed container with object-fit: cover. Gallery and Admin may scroll. Mobile intentionally scrolls.

Edit actual team names only at the bottom of data.js.

After uploading all files to GitHub, commit the changes, wait for Pages deployment, then open the site in an InPrivate window or press Ctrl+F5.
