# FCPL 2026 latest accurate player showcase

This version was rebuilt from the latest workbook: FCPL 2026 _ Official Player Registration (Responses) (2).xlsx.

- 48 registration rows were imported in exact worksheet order.
- Player IDs run from P001 to P048.
- No deduplication or sorting was applied.
- Public profile fields come directly from Full name, Age, Phase, Cricket Playing Experience, Previous Tournament, Primary Playing Role, Batting Style, and Bowling Style.
- Numeric age is used only to calculate the public category and is not displayed.

Before publishing, open PLAYER_DATA_VALIDATION.csv and verify the Player ID-to-name mapping. The CSV is for organizer review only and should not be uploaded publicly because it contains numeric age and Google Drive file IDs.

Upload only these public website files to GitHub:
- index.html
- styles.css
- app.js
- data.js
- fcpl-logo.png

Replace all existing copies of those files and commit the changes. Do not upload PLAYER_DATA_VALIDATION.csv.
